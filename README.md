# 战略推演 · strategy-lab

A workspace for strategic thinking, decision-making, strategy generation, and scenario simulation.

做决定之前，先把未来推演一遍。在线使用：https://emanon4.github.io/strategy-lab/

一个给个人用的决策推演台。每次只为一个决定走五步：

1. **定题**：把决定写成一个问题，列出两到四条可以走的路，写下底线和你最在乎的东西。
2. **布局**：**势力图**以你为中心，把各方拖到三圈里，越近影响越大（沿用北约 APP-6 军标的框形区分阵营，大小是实力）；**地基图**按把握和重要性摆放事实与假设，左上角是该先验证的。
3. **推演**：每条路拆成几个关键节点，每个节点有一个"有利概率"和顺、逆两种后果。
   - **命运河**：横轴是时间，纵轴是累计得分，线宽是概率。所有未来如何分叉、汇合、落在哪里，一眼看清。拖动节点上方的蓝红条直接调概率。
   - **结局分布**：几条路共用一条得分轴上下叠放，柱高是概率，三角是期望。底线是一条可以拖动的红线，触底概率随之重算。
   - **掷骰**：一颗粒子沿命运河走出一种具体的未来；连掷 50 次，看分布从随机里长出来。
   - **什么最关键**：龙卷风图显示每个节点能让期望摆动多少；信息价值提示告诉你，哪条信息值得在落子之前先去打听。
4. **落子**：选一条路，做事前验尸，设好绊线（看到什么信号就调头），写下 48 小时内能做的第一步。
5. **决策书**：一页纸记下这次决定，附上命运河。到了复盘日回来，在命运河上标出实际走过的路，分清是推理对了还是运气好；首页会累积你的节点校准图。

## AI

AI 是可选的。它负责帮你把问题问对、补充漏掉的行动者和假设、为每条路给出关键节点和概率、扮演红队。每一步都可以完全手动完成。

在设置里填入你自己的 API Key：

- **Claude 官方 API**：默认模型 `claude-sonnet-5-5`，可以改；用中转服务时填写接口地址。
- **OpenAI 兼容接口**：填写接口地址和模型名。部分服务不允许网页直接调用，测试连接失败时可以换一个。

Key 只保存在你的浏览器里，由浏览器直接发给你选择的服务。

## 数据

所有推演保存在浏览器的 localStorage 里，不上传到任何服务器。在设置里可以导出和导入 JSON 备份。

## 部署

纯静态页面（`index.html`、`app.css`、`app.js`、`viz.js`），没有构建步骤，直接用 GitHub Pages 从 `main` 分支根目录发布。
